Permission Usage Explanation

This page explains why our application Chrono Verify requires certain device permissions. Our app analyzes watches using camera scanning and image processing to help users understand authenticity.

📷 Camera Permission

Camera access is required to allow users to scan watches directly from the device camera. This helps our system analyze visual details and assist in authenticity evaluation.

🖼️ Photos & File Access (Gallery)

Users may upload existing images from their gallery instead of taking a new photo. File access is used only for selecting images chosen by the user for analysis. We do not access files without user action.

🔔 Notification Permission

Notification access may be used in future updates to provide important alerts, analysis results, or app-related updates. Notifications will only be used for essential app functionality.

🔒 User Privacy

We respect user privacy. Permissions are requested solely to enable core features. No unnecessary data is collected or shared without user consent.

If you have any questions, please contact our support team.
